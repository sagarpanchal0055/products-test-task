# React + Vite Starter Template

This is a minimal React + Vite starter setup that includes:

- Fast development with Vite
- Hot Module Replacement (HMR)
- Mock APIs using `json-server`

---

## Getting Started

### Install Dependencies

```
npm install
```

### Start Mock API Server

```
npm run json-server
```

### 🚀 Run the Development Server

```
npm run dev
```

### Note

You can modify db.json to simulate your own REST API endpoints.
